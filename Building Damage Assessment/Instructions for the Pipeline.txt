Instructions for the Pipeline:

The Dataset can be downloaded from the xBD website (https://xview2.org/)
For smooth running of the code, we advise to organise the downloaded data in the path matching the code (or changes would be needed).
An example of the path would be: Tier_1 -> Images.zip
                                        -> Labels.zip
